# 小虾记账 图标资源

请将以下图标文件放入此目录：

## 必需文件

| 文件名 | 尺寸 | 用途 |
|--------|------|------|
| icon.png | 256x256 | Linux/Mac 图标 |
| icon.ico | 256x256 | Windows 图标（需包含 16/32/48/256 多尺寸） |

## 图标设计建议

- **主视觉**：🦞 虾/龙虾元素
- **配色**：主色 #1e40af (蓝色) + 强调色 #f59e0b (金色)
- **风格**：扁平化、现代感、专业会计工具气质
- **背景**：透明或圆角矩形

## 在线生成工具推荐

1. **ICO转换**: https://convertico.com/
2. **PNG多尺寸**: 使用任何图像编辑软件导出
3. **完整图标集**: 可从 Figma/Sketch 设计后导出

## 临时方案（开发阶段）

如果没有准备图标，可以：
1. 从官网 https://github.com/Yuren0312/xiaojizhang 获取favicon
2. 使用在线工具转换为 ICO 格式
3. 或暂时使用 Electron 默认图标
