# 会计报表自动计算 · 使用说明

读上月报表和本月单据，自动算出本月 5 张会计报表。

---

## 一、第一次：装环境（只做一次）

### 1. 装 Python

去 https://www.python.org/downloads/ 下载 Python 3.10 以上版本，
**安装时务必勾选 "Add Python to PATH"**。

### 2. 装依赖

在本文件夹里打开命令行（地址栏输入 `cmd` 回车），运行：

```
pip install -r requirements.txt
```

### 3. 验证装好了

```
python -m pytest tests/ -q
```

全部 passed 就说明环境没问题。如果本机放了历史账套数据，回归比对也会一并跑，
用上月输入算本月、与人工编制的成品逐单元格比对。

---

## 二、每月出表

### 第 1 步：准备输入，全部放进 `输入` 文件夹

| 要放什么 | 从哪来 | 必须吗 |
|---|---|---|
| 本月工行对账单 PDF | 企业网银导出 | **必须** |
| 本月业务回单 PDF | 网银导出，用于核对 | 可选 |
| `业务事项.xlsx` | 手工填，见下 | 有就填 |
| 上月 5 表 PDF | 财务软件导出 | **仅第一次需要** |

> 从第二个月开始，程序会自动读 `输出` 文件夹里上月生成的报表来接续，
> 不用再导出上月 5 表 PDF。

### 第 2 步：填 `业务事项.xlsx`

**这一步最容易漏。** 银行对账单只能反映「钱动了」的业务。
挂账的费用、计提的折旧、应收应付这些**不动钱**的业务，对账单里一个字都没有，
必须在这张表里填，否则报表会少算。

打开 `输入\业务事项.xlsx`，接着已有的行往下写：

| 日期 | 摘要 | 借方科目 | 贷方科目 | 金额 | 来源 |
|---|---|---|---|---|---|
| 2026-06-30 | 本月云服务费（未结算） | 营业成本 | 应付账款 | 1000.00 | 供应商账单 |
| 2026-06-30 | 计提本月折旧 | 管理费用 | 累计折旧 | 500.00 | 折旧表 |

- **日期**写 `YYYY-MM-DD`（也兼容 `2026/6/5`、`20260605`、Excel 日期，程序自动转标准格式），程序按它判断属于哪个月，往月的行留着不影响；
  日期缺失或写错（如 `2026年6月`）会**明确报错并指出是哪一行**，不会悄悄漏掉这笔记账
- **科目名**必须是 `accounting_report\rules\accounts.yaml` 里定义过的，写错会报错并提示
- 常见的几笔：
  - 收到发票但还没付款 → 借 相应费用科目 / 贷 应付账款
  - 计提折旧 → 借 管理费用 / 贷 累计折旧
  - 计提工资 → 借 管理费用 / 贷 应付职工薪酬

### 第 3 步：双击 `运行.bat`

问你要出哪个月的表，回车用默认（上个月），或者自己输 `2026-06` 这种格式。

结果出在 `输出\2026-06 会计报表.xlsx`，版式跟现在用的报表完全一样。

**同一批运算还会出 8 份配套文件**（都在 `输出\` 里）：

| 文件 | 是什么 |
|---|---|
| 银行对账报告 | 银行流水跟账面逐笔核对 + 余额调节表 |
| 核算汇总表 | 科目余额、理财/往来/费用明细 |
| 分析简报 | 收支结构、费用占比、异常检测、风险建议 |
| 增值税申报底稿 | 发票自动识别（PDF 直接放 `输入\发票`），进项/销项分开 |
| 企业所得税预缴底稿 | 自动判定小微企业（利润/资产/人数） |
| 个税扣缴明细表 | 员工工资表 → 个税明细（工资表放 `输入\工资社保`） |
| 记账凭证 | 从分录生成的标准记账凭证（记字N号，含制证/审核栏） |
| 试算平衡表 | 科目期初/本期/期末借贷发生额，借贷必平校验 |

税务底稿需要的数据源（资产台账、员工名册、工资表）缺了会标 `[模板]` 并在文件名提示；
补齐后自动升级为正式输出。示例数据可用 `python tools/generate_ledger_samples.py` 生成。

**银行对账报告三表同源口径**：`对账明细`/`未达账项`/`余额调节表` 三个 sheet
共用同一份配对结果——银行流水与账面分录按「金额相等 + 方向一致 + 同一月份」
一一对应配对（凭证常在月末批量入账、银行流水是实际入账日，同一笔跨几天属正常，
不按逐日窗口）；配对不到的才算未达账项，余额调节表与未达账项两表永远对得上。
跨 PDF 重复上传的同一笔流水会被自动去重（去重键含对方户名与摘要，同日同额但
产品/对方不同的多笔交易不会误并）。

**核算汇总表按账期口径**：理财/往来/费用明细只列**当月**交易（多月导出的
明细账会自动按月裁剪，不会把全年的未来日期流水带进当月报表）；往来账龄按
「报表账期末日」计算（同一报表无论哪天重跑数字不变）。若上传的科目余额表
快照不是本月账期（比如拿 6 月快照跑 1 月账期），运行日志与页面会明确告警，
核算汇总表第 1 页仍按输入文件原样转述，请换当月科目余额表后重跑。

## 三、看懂运行结果

正常跑完长这样：

```
本月分录 3 笔：
  2026-06-05  借 货币资金 / 贷 营业收入    5000.00   客户货款
  2026-06-20  借 管理费用 / 贷 货币资金     800.00   办公费
  2026-06-30  借 营业成本 / 贷 应付账款    1000.00   云服务费（未结算）

单据核对：
  回单核对通过：2026-06-05 客户货款 5000.00

勾稽校验：
  ✓ 分录借贷平衡（3 笔）
  ✓ 资产负债表平衡
  ✓ 未分配利润勾稽
  ✓ 现金流量表与货币资金勾稽
  ✓ 季报与月报衔接（第 2 季度）
```

**「本月分录」那几行要逐笔看一眼**——这是程序对本月业务的理解。
如果哪笔科目记得不对，说明关键词规则要调（见下）。

## 四、出错了怎么办

程序的原则是：**宁可不出表，也不出一张看着像样、实际不平的表。**
所以报错不是坏事，是它在拦你。

### 「以下银行流水无法归类到科目」

最常见。说明有笔流水程序没见过，比如：

```
以下银行流水无法归类到科目，请在 accounting_report/rules/mapping.yaml
补充 bank_rules 后重跑：
  2026-06-10  某某科技货款  对方:某某科技有限公司  借0 贷5000.00
```

处理：用记事本打开 `accounting_report\rules\mapping.yaml`，
照着已有格式加一条（注意缩进要对齐）：

```yaml
  - match: 某某科技
    account: 营业收入
    note: 客户货款
```

`match` 是关键词（会在摘要和对方户名里找），`account` 是对应科目。
存盘后重跑即可。**加过一次以后就一直有效。**

### 「未定义的科目」

`业务事项.xlsx` 里科目名写错了。正确的科目名见
`accounting_report\rules\accounts.yaml`，比如是「研究费用」不是「研发费用」。

### 「勾稽校验未通过」

程序算出来的表不平。**别手工改 xlsx 凑数**，把完整提示发给开发。

### 「找不到上月报表」

`输入` 里要有上月 5 表 PDF，或 `输出` 里要有上月本程序生成的 xlsx。

## 五、需要留意的地方

1. **每月看一眼分录明细**，确认程序对业务的理解没跑偏。
2. **不走银行的业务别忘了填 `业务事项.xlsx`**，这是唯一需要人工判断的环节。
3. **跨季度（7月）和跨年（明年1月）** 这两个月的输出建议多核一遍——
   季报要重新起算、本年累计要清零，逻辑写了但还没用真实数据验证过。
4. 输出文件**不要手工改**。改了下个月接续取数会错。有问题改规则、重跑。
5. **银行对账单 PDF 借方/贷方列空白补动账**：若银行对账单 PDF 某行
   借方/贷方金额列打印为空但余额变化隐含动账，引擎会按余额连续性
   自动补足借/贷（标 `[按余额连续性推断动账]`）。常见于网上银行导出
   的 0.34 元验证款、退款等明细。若自动补的金额与实际不符，请补一份
   借方/贷方列正常的对账单 PDF 重新跑。

## 六、文件都是干什么的

| 文件/文件夹 | 作用 |
|---|---|
| `运行.bat` | 双击这个就行 |
| `输入\` | 放每月的单据 |
| `输出\` | 生成的报表在这里，也是下月的取数来源 |
| `accounting_report\rules\` | **规则文件，改这里不用改代码** |
| `accounting_report\` 其余 | 程序本体 |
| `tests\` | 自检用 |
| `README.md` | 给开发看的技术说明 |
